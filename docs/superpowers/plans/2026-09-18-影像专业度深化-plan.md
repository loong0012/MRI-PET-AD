### P3 · longitudinal_service 计算逻辑

**依赖**: P1, P2
**产出**: `ad-screen-backend/services/longitudinal_service.py`

**步骤**:
1. 创建 `services/longitudinal_service.py`
2. 实现 `compute_metrics(patient_no: str, db: Session) -> dict`：
   - 查询 `CaseRecord` where `patient_no == patient_no and is_deleted == False`，按 `exam_date` 升序
   - 每期 left join `AnalysisResult` 取 `hippocampusVolumeL/R`/`meanSUV`/`corticalThickness`/`ventricleVolume`/`mtaScore`
   - 写入/更新 `LongitudinalMetric` (upsert by `patient_no + case_id`)
   - 单期：`annual_rate_*` = null，`niaaa_stage` = "baseline"
3. 实现 `compute_rates(timepoints: list) -> dict`：
   - 对相邻两期算 `(后值-前值)/间隔年`，间隔年 = `(exam_date[1]-exam_date[0]).days/365.25`
   - 多期取最近一对
   - `exam_date` 格式归一化：支持 `yyyy-mm-dd`/`yyyymmdd`/`yyyy/mm/dd`，统一转 `yyyy-mm-dd`
4. 实现 `classify_niaaa(rates: dict, prev_metrics: dict) -> str`：
   - 海马体积年萎缩率 > 3%/年 (相对前值) → +2
   - SUVr 年降幅 > 2%/年 → +1
   - 皮层厚度年降幅 > 0.05mm/年 → +1
   - 累加分数：0=CN, 1-2=MCI, 3-4=AD-E, ≥5=AD-L
5. 错误处理：
   - 缺失 `AnalysisResult` → 跳过该期，`progression_note` 标注"该期 AI 分析未完成"
   - 间隔 <30 天 → 仍计算但 `progression_note` 标注"间隔过短，变化率仅供参考"
   - `exam_date` 缺失 → 跳过该期，日志告警

**验证**:
- 单测 `tests/test_longitudinal_service.py` (在 P5 完成)
- 手动：在 SQLite 插入同 `patient_no` 的 2 期病例，调用 `compute_metrics`，检查 `annual_rate_hv` 计算正确

   ```typescript
   export function useVoxelFromPixel(canvasSize: number, sliceCount: number) {
     const toVoxel = (px: number) => Math.floor((px / canvasSize) * sliceCount);
     return { toVoxel };
   }
   ```
2. `ViewerView.vue`：
   - 顶部新增"三平面模式"开关 `<el-switch v-model="triplePlaneMode">`，默认 false
   - 三平面模式开启时切换布局：单视口 → 三视口并排 (轴位/矢状位/冠状位)
   - 三视口各为 `<MedicalViewport>` 实例，传入不同 `orientation` prop
   - 三视口共享 `sliceIdxAxial` / `sliceIdxSagittal` / `sliceIdxCoronal` 状态
   - 任一视口 click → 通过 `useVoxelFromPixel` 换算 → 更新另两视口 sliceIdx：
     - 轴位 `(px, py)` → `voxelAx = toVoxel(px)`, `voxelAy = toVoxel(py)` → 矢状位 slice = voxelAx，冠状位 slice = voxelAy
     - 矢状位 `(px, py)` → 轴位 slice = toVoxel(px)，冠状位 slice = toVoxel(py)
     - 冠状位 `(px, py)` → 轴位 slice = toVoxel(py)，矢状位 slice = toVoxel(px)
